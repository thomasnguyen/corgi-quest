# VR Demo - Quick Reference Card

## Voice Commands (In Order)

1. **"Start training Leave It"** → Activates training mode
2. **"Mark rep"** → Increment counter (repeat 5 times)
3. **"End session, completed 5 Leave It reps"** → Finish and log

## Timing

- **Total**: 15-25 seconds
- **Reps**: ~2 seconds between each "Mark rep"
- **Sync delay**: Max 3 seconds

## Backup Plan

If API fails → App uses mock data automatically → Demo continues
